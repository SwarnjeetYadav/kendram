- Safe refactoring plan

- Expected outcomes and limitations

## Key Technical Findings
- N plus one database query pattern during workload calculation
- Missing project membership validation for explicit assignee
- Incomplete request validation
- Authorization logic coupled to controller
- Internal error details exposed to clients
- Notification handling coupled to the main request
- Monolithic controller responsibilities
- Magic values and unclear naming
- No explicit consistency policy for task and activity writes
